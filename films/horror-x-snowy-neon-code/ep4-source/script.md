# Snowy Neon EP4 — บทเต็ม 180 วินาที (3:00)

**สรุปสำหรับคนอ่าน:** นุ่นหันหลังครบแล้วพบว่าไม่มีใครอยู่ข้างหลัง — ขอบผ้าขาว
ที่เห็นเป็นมุมผ้าของเธอเองที่ร่วงลงพื้น แต่เสียง “ใส่เหรียญ” และเหรียญอุ่นที่
ปรากฏในถาดบอกว่าอะไรบางอย่างยังทำงานต่อ เธอค้นพบว่าเครื่องซักอีกตัวหมุน
เองพร้อมผ้าผืนใหม่ที่ยังไม่มีชื่อปัก แล้วตัดสินใจออกจากร้านผ่านประตูหน้าครั้ง
แรกในฐานะคืนสุดท้ายของการทำงาน ระหว่างยืนอยู่ข้างนอกในเช้าที่หิมะหยุดตก
เธอเห็นเงาผ้าขาวยืนอยู่ตรงข้ามถนน และตอนหันมองกระจกเงากลับพบว่าเงานั้น
ยืนอยู่ข้างหลังเธอบนทางเท้า เหรียญในกระเป๋าของเธอยังอุ่นอยู่

**Logline:** คืนสุดท้ายของนุ่นที่ร้านซักผ้าเริ่มต้นด้วยคำถามว่าเสียงข้างหลัง
คือใคร — แต่คำตอบที่เธอได้คือการค้นพบว่าพิธีกรรมยังดำเนินต่อโดยไม่มีเธอ
และครั้งแรกที่เธอออกไปข้างนอก เงาผ้าขาวก็ยืนรออยู่ที่นั่นแล้ว

- ความยาว: **180.0 s** (1080×1920, 30 fps) — ต่อจาก EP3 (`turn` shot) โดยตรง
- ผู้เล่า: นุ่น (เสียง Leda โทนปกติ, บุรุษที่หนึ่ง “ฉัน”) · ปีศาจเงียบตลอด
- ทุกรายละเอียดการผลิตดู `TREATMENT.md` ในโฟลเดอร์เดียวกัน

## ตรวจเวลารวม

- ช็อต/beat ครอบ 0.00 → 180.00 ต่อเนื่องไม่มีช่องว่างในระดับเรื่อง
- บทพากย์ 24 บรรทัด จบที่ ~169.8 s, เงียบท้าย ~10.2 s
- ไม่มีบรรทัดทับกัน (ทุกช่วงห่างกัน ≥0.4 s)
- ประมาณการอิงอัตรา Leda ~0.105 s/ตัวอักษรไทย + gap ฉากตามแบบ EP2/EP3;
  ตัวเลขจริงจะวัดจากเสียงหลังผลิต (`timing.mjs`)

## กฎที่ต้องรักษาตอนผลิต

- ผ้าขาวทุกเงา: ไร้หน้า ไม่มีฝีเท้า ไม่มีเลือด ไม่มีเสียง
- ปีศาจไม่มีบทพูดในตอนนี้ (ต่างจาก EP3 ที่มี “ใส่เหรียญ” ครั้งเดียว)
- นุ่นถือผ้าผืนมีชื่อ “นุ่น” ตลอดตอน — ไม่เคยปล่อย
- ไม่เปิดเผยหน้าหรือร่างของผู้มาเยือน · ไม่ใช้ CCTV/ย้อนเวลา/นับเช้าซ้ำ
- แสง: เทาเช้าอ่อน → ขาวเย็นริมฟ้า (ไม่ใช่ไทม์แลปส์) → นอกอาคารเป็นยามเช้า
  ขุ่น ๆ หิมะเบาบนฟุตบาทและไหล่เสื้อ
