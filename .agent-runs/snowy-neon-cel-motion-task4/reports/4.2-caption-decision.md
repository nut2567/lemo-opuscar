## Exact render override

**Jessica render URL parameter: `?capvw=1.7778`**

### Mechanism confirmed in `entry.mjs` (lines 15–18)

```javascript
// ?capvw=<vw> overrides the caption font size for size-comparison renders
// (19.2px@1080 = 1.7778vw; 22.4px = 2.0741vw; 24px = 2.2222vw).
const capvw = new URLSearchParams(location.search).get('capvw');
if (capvw) document.documentElement.style.setProperty('--cap-size', `${Number(capvw)}vw`);
```

The query parameter `capvw` is read as a number and set directly as a CSS custom property `--cap-size` in `vw` units. The `index.html` caption span uses `font-size: var(--cap-size, 2.0741vw)` (line 21), so:

- **Without `?capvw=`**: renders at 2.0741 vw (22.4 px at 1080 px) — the current default.
- **With `?capvw=1.7778`**: renders at 1.7778 vw (19.2 px at 1080 px) — the selected size.

The override is render-time only. It does not change `index.html` or `entry.mjs`.
