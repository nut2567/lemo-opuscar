not rig keys. All of it will be mapped to the coordinator's 1.0 API
(`FrameContext { edition, frame, seconds, cue, shot, camera, sourceSeconds }`,
`PoseSample` fields per `docs/plans/snowy-neon-cel-motion.th.md` §API) by the
pose-data task; nothing here modifies that contract.

**Legend:** `[S]` = directly supported by a cited source value;
`[P]` = proposed animation (plan-language or inference, needs implementation
and frame verification). Listening-based word timing is **pending**: the
Jessica WAV is absent from this checkout, so all word beats below are the
ones already recorded inside `jessica.json`/`timeline.mjs`/plan — none were
re-derived by ear.

## Cross-cue constraints and invariants `[S unless noted]`

- **Cel identity**: all acting is pose-layer motion over the approved cel model (`models/cel/*`); no face/hair/outfit redraw. Current cel components resolve motion from `t` (= `sourceSeconds` via `main.mjs nunLayer(st)`); the new pose system must override/augment this through the 1.0 contract without changing default output when motion mode is off.
- **Counter clip**: world y1110 (`main.mjs` `nunClip` rect height 1110); everything below is hidden — feet/legs only matter where she is visibly in front of the counter (walk-in cue 2) or if framing reveals them; otherwise sell weight through torso/hips.
- **Cloth customer**: featureless by design (`characters.mjs drawCloth` — no face/hands/feet ever); `cloth:true` only on `customer`+ in cues 1–6 range (just `customer`). No footsteps anywhere — including cue-2 walk (feet move, no step audio; `eventsFor` has no footstep type and cue-10 text forbids them).
- **No new plot beats**: no coin leaves the tray in cues 1–6 (the 21.82 coin is the overlay's, not hers); no literal cloth-prop feeding unless coordinator approves a new visual; customer does nothing but stand/sway (`clothMotion` only).
- **SRT/captions**: byte-fixed; no retiming proposed anywhere above.
- **Determinism**: every beat above must be expressible as pure functions of `FrameContext` (frame/seconds/cue/shot) — no wall-clock, no `Math.random` (plan §API).
