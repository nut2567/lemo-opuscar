## D-2 — contacts/holds interpolation (fixed)

**Change:** `contacts.interp` and `holds.interp` set from `"smooth"` to
`"step"`.

**Contract basis:** API.md resolver rules — `'step'` holds `k_i` within
`[k_i.t,k_{i+1}.t)`; only numeric leaves interpolate and enums/strings/
booleans/nulls never do. `contacts`/`holds` are "resolved intents, not
measured rig output," so their numeric advisory fields
(`ContactIntent.targetWorld`, `HoldState.*.sinceSeconds`) must not glide
between sparse beat keys (e.g. `sinceSeconds` producing meaningless
intermediate timestamps). Step makes each intent change discretely at its
key — the semantic the notes always claimed.
